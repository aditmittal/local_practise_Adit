# EPAM Java Interview Prep

Complete Java coding interview preparation project with problem-solving algorithms for arrays and strings.

## How To Run

### Run Main Class

```bash
mvn clean install
```

Then run `Main.java` from your IDE.

### Run Tests

```bash
mvn test
```

## Problems Included

### Array Problems (ArrayProblems.java)

1. **Find Second Largest** - Find second largest element in array
2. **Move Zeros To End** - Move all zeros to end of array
3. **Remove Duplicates** - Remove duplicates from sorted array
4. **Merge Two Sorted Arrays** - Merge two sorted arrays into one
5. **Frequency Count** - Count frequency of each element
6. **Find Missing Number** - Find missing number in sequence
7. **Rotate Array By K Steps** - Rotate array by k positions

### String Problems (StringProblems.java)

1. **Palindrome Check** - Check if string is palindrome
2. **Reverse String** - Reverse a string
3. **Character Frequency** - Count character frequencies
4. **Anagram Check** - Check if two strings are anagrams
